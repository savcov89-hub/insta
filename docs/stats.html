Ролики

Нажми на заголовок столбца, чтобы отсортировать. «Подписок ≈» — оценка, объяснение под таблицей.

Подписок с ролика Instagram через API не отдаёт (в приложении они есть, в API для Reels — нет). Поэтому оценка: прирост подписчиков между замерами делится между роликами пропорционально тому, сколько просмотров каждый набрал за это время. Подписки из историй и шапки тоже попадают в ролики, так что это ориентир, а не точное число. Удержание — доля тех, кто не пролистал первые 3 секунды.
